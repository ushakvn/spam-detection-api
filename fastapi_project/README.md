# 🚀 Spam Detection API

## 📌 Project Overview
This project is a Machine Learning API built using FastAPI that classifies text messages as **Spam** or **Not Spam**.

---

## 🧠 Features
- Real-time spam prediction
- REST API using FastAPI
- NLP using CountVectorizer
- Machine Learning model (Naive Bayes)
- Model saving & loading using joblib

---

## ⚙️ Tech Stack
- Python
- FastAPI
- Scikit-learn
- NLP
- Uvicorn

---

## 🔄 How It Works
User Input → API → Text Processing → ML Model → Prediction
